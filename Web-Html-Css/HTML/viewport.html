Bem-vindo ao curso de Viewport

O elemento meta viewport é usado para controlar a forma como uma página da web é exibida em dispositivos móveis. Ele permite que você defina a largura e a escala da página, garantindo que o conteúdo seja exibido corretamente em diferentes tamanhos de tela.

Ao usar o meta viewport, você pode definir a largura da página para corresponder à largura do dispositivo, permitindo que o conteúdo se ajuste automaticamente. Além disso, você pode controlar a escala inicial da página, permitindo que os usuários ampliem ou reduzam o conteúdo conforme necessário.

Em resumo, o meta viewport é uma ferramenta essencial para criar páginas da web responsivas e garantir uma experiência de usuário consistente em dispositivos móveis.
